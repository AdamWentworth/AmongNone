Space Cadet source assets
Tripo-generated character, with the existing locally prepared rig and animation.
Uses the accepted upper-backplate cleanup version, before the rejected forearm edits.
Geometry, skinning, and texture content are copied unchanged from that review package.
Height approximately 1.85 m; 62 bones. Right cannon deforms rigidly with hand_r.
Base color is sRGB, normal is DirectX, ORM packs occlusion/roughness/metallic.
Idle_CannonReady is a static ready pose; Run_CannonReady is the existing forward loop.
The editable Blender master remains outside this game repository.
