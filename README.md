# AmongNone

AmongNone is a game prototype built in Unreal Engine 5.8 using C++ and Blueprints. The project includes third-person player controls, basic enemy chase AI, and early inventory and interaction systems. There’s C++ work in place for interactable objects such as crates, shrines, and the reactor.

## Test maps

- `PlayerTestRoom` demonstrates third-person movement, camera controls, and cannon aiming.
- `EnemyTestRoom` demonstrates basic enemy chase behavior.
